# Subagent Use Checklist

Before spawning:

- Confirm council mode is justified.
- Select only inherited leaves already listed in the council skill.
- Assign one narrow question per subagent.
- Give only the context needed for that question.
- Require the standard return shape.

While synthesizing:

- Compare assumptions before comparing conclusions.
- Separate findings from recommendations.
- Identify conflicts explicitly.
- Choose one recommendation, or state why the uncertainty blocks a choice.
- Record verification status and remaining uncertainty.

Never:

- Spawn a council-specific role.
- Ask a subagent to coordinate another subagent.
- Use subagents for ordinary routing ambiguity.
- Use more specialists than the task needs.
