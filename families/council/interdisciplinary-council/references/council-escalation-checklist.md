# Council Escalation Checklist

Use council mode only when the answer to at least one question is yes:

- Does the task genuinely span multiple specialist families?
- Would one specialist likely miss a material risk?
- Are there competing interpretations that need reconciliation?
- Would controlled parallel analysis materially improve the result?

Do not use council mode when:

- The request is simply unclear.
- One leaf has a clear primary claim.
- The user wants a quick first pass.
- A clarifying question would resolve routing.

Escalation should be rare, explicit, and bounded.
